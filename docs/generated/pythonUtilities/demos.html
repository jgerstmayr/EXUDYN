Module: demos

The demos library includes basic demos which are available directly after installation; For advanced demos, see python/Examples and python/TestModels

  • Date: 2023-01-12

Function: DemoSolutionFile

DemoSolutionFile(name)

  • function description: The solution file of a demo, in a directory that is created if it does not exist.

  • input:

    • name: the file name, e.g. ‘demo1.txt’

  • output: the path the demo writes to

Function: Demo1

Demo1(showAll = True)

  • function description: very simple demo to show that exudyn is correctly installed; does not require graphics; similar to Examples/myFirstExample.py

Relevant Examples (Ex) and TestModels (TM) with weblink to github: xExudynConfigSpecial.py (Ex), allExudynModulesTest.py (TM)

Function: Demo2

Demo2(showAll = True)

  • function description: advanced demo, showing that graphics is available; similar to Examples/rigid3Dexample.py

Relevant Examples (Ex) and TestModels (TM) with weblink to github: allExudynModulesTest.py (TM)
