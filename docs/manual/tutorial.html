Tutorial

The tutorials start with a mass point on a spring-damper, the shortest possible model, continue with 3D rigid bodies and revolute joints, and show flexible beams, symbolic user functions and a flexible body of the floating frame of reference formulation.

A large number of examples, some of them quite advanced, can be found in:

  • python/Examples

  • python/TestModels

The tutorials are notebooks, in python/Notebooks/: the pages show their code and the outputs of their last run, and the same code is an example in python/Examples/notebooks/. The mass-spring-damper and the rigid body tutorials come twice: built from the items, and with the Create functions.
