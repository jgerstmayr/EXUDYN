# tools/generators/ — the new generator code

Maintainer tools around [`definitions/`](../../definitions/README.md), the input of code
generation. The six established generators still live in `src/pythonGenerator/`; the code here
grows as Phase 3 splits them into emitters (revision plan step 33).

| file | what it does | used by |
|---|---|---|
| `definitionLoader.py` | imports `definitions/` and hands each class to the generators as `(parseInfo, parameterList)` - the form their old line parser produced - so their per-class code is unchanged. Removed once the generators read `definitions/` directly (step 33, part 2) | `itemModel.LegacyItems()`, `structureModel.LegacyStructures()` |
| `itemModel.py` | facts about items shared by the emitters: type tables and predicates, user-function types, how a `definitions/` member renders to the old string forms, per-item accessors | the item emitters, `definitionLoader.py` |
| `itemInterfaceEmitter.py` | emits `python/exudyn/itemInterface.py` from `definitions/`; `--output` for another target | `tools/regenerate.py` |
| `itemHeaderEmitter.py` | emits the per-item C++ headers `C/Main/Visu<Item>.h`, `PySymbolicUserFunctionSet.h` / `PythonUserFunctionsTemplates.h` and `objectFactoryAutoReg.h`; `--output-dir` for another target | `tools/regenerate.py` |
| `miniExampleEmitter.py` | emits `python/TestModels/MiniExamples/<Item>.py` and `miniExamplesFileList.py`; `--output-dir` | `tools/regenerate.py` |
| `itemDocsEmitter.py` | emits the item reference documentation: `docs/RST/items/*.rst`, `docs/theDoc/itemDefinition.tex`, `docs/RST/confHelperItems.py` | `tools/regenerate.py` |
| `structureModel.py` | facts about structures shared by the structure emitters: type tables, predicates on classes and parameters, sorted parameters, typical paths, the old string records | the structure emitters |
| `structureHeaderEmitter.py` | emits the structure C++ headers (`SimulationSettings.h`, `VisualizationSettings.h`, ...), `DictionariesGetSet.h` and `pybind_modules.h` | `tools/regenerate.py` |
| `structureStubEmitter.py` | emits the stub fragment `src/pythonGenerator/generated/stubSystemStructures.pyi` read by `createStubFiles.py` | `tools/regenerate.py` |
| `structureDocsEmitter.py` | emits the structure reference documentation: `docs/RST/structures/*.rst`, `docs/theDoc/interfaces.tex` | `tools/regenerate.py` |
| `enumEmitter.py` | generates `src/Autogenerated/EnumTypes.h` (enums and string functions) from `definitions/enumTypes.py`, after checking unique names and values | `pybindEmitter.py`, on every generation |
| `utilityDocsModel.py` | the parser of the `#**` comments in the utility modules and the text helpers shared by the three emitters below | the utility emitters |
| `mainSystemExtensionsEmitter.py` | assembles the **shipped** `python/exudyn/mainSystemExtensions.py` from `src/pythonGenerator/mainSystemExtensionsHeader.py` plus one link per `#**belongsTo` function | `tools/regenerate.py` |
| `mainSystemExtensionDocsEmitter.py` | emits `MainSystemExt.rst`/`MainSystemCreateExt.rst` (read by `pybindEmitter.py`), their `.tex` and `stubAutoBindingsExt.pyi` | `tools/regenerate.py`, before `pybindEmitter.py` |
| `utilityDocsEmitter.py` | emits the utility module reference: `docs/RST/pythonUtilities/*.rst`, `pythonUtilitiesDescription.tex`, `confHelperPyUtilities.py` | `tools/regenerate.py` |
| `pybindEmitter.py` | replays `definitions/pybind*.py` into `pybind_manual_classes.h`, the stub fragments `stubAutoBindings.pyi` / `stubSymbolic.pyi` / `stubEnums.pyi`, `manual_interfaces.tex`, `docs/RST/cInterface/*.rst` and `confHelper.py` | `tools/regenerate.py` |
| `definitionValidator.py` | the cross-file checks on `definitions/`: every virtual item function overrides a real declaration in the C++ parent headers, `fromParent` members exist in the parent, no duplicate member, shaped defaults have the right size; in `pybind*.py`, argument/default/type lists agree, no function is declared twice, Begin/End steering calls pair up; reports all violations | `tools/regenerate.py`, before the generators run (exit code 3) |
| `outputVariableEmitter.py` | generates `src/Autogenerated/OutputVariableTypes.h` from `definitions/outputVariableTypes.py`, after checking the bit allocation | `pybindEmitter.py`, on every generation |

## Changing a definition

Edit `definitions/`, then in `venvExuP313`:

```
python tools/regenerate.py --check
```

It validates the definitions, runs all generators and reports what changed in the generated set.
